# Deploy to Golem Cloud

Golem Cloud is hosted version of Golem. It is easiest and fastest way to run Golem [agents](/v1.6/concepts/agents),
in the cloud, at scale, without any infrastructure setup or maintenance required.

Golem Cloud can be managed by:

- [Golem CLI](/v1.6/cli)
- [REST API](/v1.6/rest-api)
