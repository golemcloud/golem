# Golem documentation

Golem is an open-source runtime for AI agents. Each agent is a long-lived, isolated instance with its own memory and filesystem that survives crashes, restarts, and deployments without repeating finished work. The same deployment runs the agents' tools, such as a shell, Node.js, npm, and the TypeScript compiler, and serves what they produce: APIs, web front-ends, files, and live streams. Permission cards limit what each agent may do.

You can run Golem on your machine from a single binary, on your own infrastructure, or on Golem Cloud.
