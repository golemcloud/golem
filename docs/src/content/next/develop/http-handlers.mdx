# Custom HTTP Handlers and Routers

Use an HTTP router when you need to handle a request as a raw HTTP envelope instead of mapping a route directly to a typed agent method. Routers support standard and custom method tokens except `CONNECT` and `TRACE`, paths under one mount, incremental request and response bodies, repeated binary headers, static files, and optional OpenAPI metadata. Protocol upgrades such as WebSockets are not supported.

This is an inbound server API. For outbound requests, use the [HTTP client](/next/develop/http).

## The raw envelope

SDKs supporting raw HTTP routers map the same contract:

```text
HttpRequest  { method, scheme, authority, path, query?, headers[], body }
HttpResponse { status, headers[], body }
HttpHeader   { name, value: bytes }
```

`path` is the full public path, not mount-relative. An absent query is distinct from an empty query. Header values are bytes and repeated fields remain separate—especially `set-cookie`. Request and response bodies are affine, backpressured streams of byte chunks.

This is a validated HTTP envelope, not the original wire representation. The host strips hop-by-hop and selected transport or proxy headers; use `scheme` and `authority` for the public origin.

The host validates the response head. Status must be 200–599, header names and values must be valid, and bodies for `HEAD`, 204, 205, and 304 responses are not polled. HTTP framing remains host-owned; do not add transfer-encoding logic.

## Define a router

Use `implementRaw` for the canonical envelope or `implement` for Fetch `Request` and `Response` adapters:

```typescript
import { defineHttpRouter } from '@golemcloud/golem-ts-sdk';

defineHttpRouter('Site')
  .mount('/site', { auth: true, cors: ['https://app.example.com'] })
  .static('/assets/*', '/public/$1')
  .implementRaw(async request => ({
    status: 200,
    headers: [{ name: 'content-type', value: new TextEncoder().encode('application/octet-stream') }],
    body: request.body,
  }));
```

Returning the request body streams an echo without buffering it. Use `.openApi(() => document)` to supply an OpenAPI 3.1.0 document. A static-only router can call `.implement()` without a handler. Fetch adapters apply Fetch normalization and restrictions; use `implementRaw` when exact envelope fidelity is required.

use golem_rust::agentic::{AgentStream, Config, Header, HttpRequest, HttpResponse, HttpRouter};
use golem_rust::http_router;

struct Site;

#[http_router(
    name = "Site",
    mount = "/site",
    auth = true,
    cors = ["https://app.example.com"],
    static_files = [("/assets/*", "/public/$1")]
)]
impl HttpRouter for Site {
    type Config = ();

    fn new(_: Config<()>) -> Self { Self }

    async fn handle(&self, request: HttpRequest) -> HttpResponse {
        HttpResponse {
            status: 200,
            headers: vec![Header {
                name: "content-type".into(),
                value: b"application/octet-stream".to_vec(),
            }],
            body: request.body,
        }
    }
}
```

Implement `async fn openapi(&self) -> String` to return OpenAPI 3.1.0 JSON. Omit `handle` for static-only or provider-only routers.

import golem.{BaseAgent, UShort}
import golem.runtime.annotations.*
import golem.runtime.http.*
import scala.concurrent.Future

@httpRouter(
  typeName = "Site",
  mount = "/site",
  staticBindings = Array(("/assets/*", "/public/$1")),
  auth = true,
  cors = Array("https://app.example.com")
)
trait Site extends BaseAgent {
  @httpHandler def serve(request: HttpRequest): Future[HttpResponse]
}

@agentImplementation()
final class SiteImpl extends Site {
  def serve(request: HttpRequest): Future[HttpResponse] = Future.successful(
    HttpResponse(
      UShort(200),
      List(HttpHeader.ascii("content-type", "application/octet-stream")),
      request.body
    )
  )
}
```

## Mounts and filesystem responses

Each router has one literal mount prefix. Mounts must not overlap ambiguously. The router itself is a parameterless ephemeral agent with snapshots disabled; handler dependencies use ordinary generated clients and manifest configuration.

Static mappings are mount-relative and are checked before the raw handler for `GET` and `HEAD`. For the examples above, `/site/assets/logo.svg` maps to `/public/logo.svg`. An exact route maps to one component filesystem path; a subtree route such as `/assets/*` must map to a target ending in `/$1`. Multiple mappings for one public route are ordered fallbacks, continuing when a file is absent. Router assets are read-only files provisioned for that router:

```yaml filename="golem.yaml"
agents:
  Site:
    files:
      - sourcePath: public
        targetPath: /public
        permissions: read-only
```

Durable agents can also expose their live filesystem:

```yaml filename="golem.yaml"
agents:
  Document:
    files:
      - sourcePath: public
        targetPath: /public
        permissions: read-write
```

Declare the agent's HTTP mount and exposed-file mapping in its SDK definition. Those responses resolve against that specific agent instance, so updates to its filesystem become visible. See [Agent Filesystem](/next/develop/agent-filesystem).

## Stream safely

Read the body incrementally and return incremental output. Do not collect an unbounded upload merely to return a response. If the handler stops reading early, close or drop the request body. If the client disconnects, the response producer observes cancellation or peer-drop; stop producing and release inputs.

Returning a response transfers its body to the runtime; do not continue consuming or reusing that stream. Close or drop request-body streams you neither consume nor transfer. Cleanup mechanisms differ by SDK, and cancellation is cooperative: producers must release captured inputs when cancelled or dropped. Do not rely on application cleanup code running after a trap or executor loss.

In MoonBit, a producer that captures an input stream should use `defer input.drop()` inside the producer, supply `on_unstarted_drop`, and stop writing on `PeerDropped`.

## Durability and recovery

Raw routers are ephemeral ingress adapters. A lost router instance is not resumed with in-memory handler state. Put durable state and long-running work in a durable agent, invoke it from the handler, and return or stream its result. Durable agent RPC retains its normal exactly-once logical invocation semantics; external effects still need idempotency support for an ambiguous crash window.

Retrying the public HTTP request starts a new router invocation; it does not automatically deduplicate earlier business operations. Carry an application-level operation ID into the durable agent when HTTP retries must be safe.

A streaming HTTP connection is resident transport, not durable storage. If a client disconnects, reconnecting does not resume arbitrary response bytes. For resumable protocol streams, use [external Durable Streams](/next/develop/durable-streams) or an agent method stream with its durable session protocol.

## Authentication, CORS, and limits

- Set `auth: true` on a mount to require the deployment's configured authentication. The host authenticates before dispatch and supplies the resulting principal where the SDK surface supports it.
- Set CORS origins on the mount. Preflight and response policy are host middleware; do not implement a second conflicting CORS layer in the handler.
- Validate content type and a declared content length early, then enforce a running byte limit while reading. Platform request, stream, memory, and concurrency limits still apply. The whole-exchange timeout includes response streaming and defaults to 300 seconds.
- Never log complete raw headers or bodies: they can contain credentials or personal data.
- Return deliberate 4xx responses for client input. An exception or trap is an invocation failure, not a stable HTTP error contract.

## Deploy

Router metadata is discovered when the component is built. Deploy normally:

```shell copy
golem build
golem deploy
```

Build extracts router metadata. Deployment validates router schemas and method roles, file-mapping syntax, mount conflicts, and required authentication configuration. OpenAPI provider documents are validated when the OpenAPI document is generated. CORS entries are exact origin strings or `*`; deployment sorts and deduplicates them rather than validating general URL syntax. Configure the public domain and security scheme in the application manifest; see [API Definitions](/next/concepts/api-definitions) and the [Application Manifest](/next/app-manifest).

<Callout type="warning">
  A router mount is public ingress. A WIT capability sandbox constrains what the component can do, but it does not authenticate callers by itself. Require auth where appropriate and authorize the principal again at the durable-agent or resource boundary.
</Callout>
