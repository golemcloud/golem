# HTTP requests

<Tabs items={["TypeScript", "Effect TypeScript", "Rust", "Scala", "MoonBit", "Go"]} storageKey="nextra-tabs-language-sdk">
<Tabs.Tab>
    HTTP requests can be made with the standard `fetch` function.

    For example:

    ```typescript
    const response = await fetch(`http://localhost:${port}/todos`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        title: "foo",
        body: "bar",
        userId: 1,
      }),
    });

    const data = await response.json();
    console.log("Body:", data);
    ```
</Tabs.Tab>

<Tabs.Tab>
    Effect TypeScript agents can use the standard `fetch` function and wrap its Promise in an Effect:

    ```typescript
    import { Effect } from "effect"

    const request = Effect.tryPromise({
      try: () => fetch(`http://localhost:${port}/todos`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          title: "foo",
          body: "bar",
          userId: 1,
        }),
      }),
      catch: (cause) => new Error("HTTP request failed", { cause }),
    }).pipe(
      Effect.flatMap((response) =>
        Effect.tryPromise({
          try: () => response.json(),
          catch: (cause) => new Error("Invalid JSON response", { cause }),
        }),
      ),
    )
    ```

    This constructs a lazy Effect. Return it from an agent method, or evaluate it with `yield* request` inside `Effect.gen`.
</Tabs.Tab>

<Tabs.Tab>
    Use `golem_rust::http` for outgoing WASI HTTP p3 requests. It reexports standard HTTP request and response types; no separate HTTP client crate is needed.

    For example, inside an async agent method:

    ```rust
    use golem_rust::http::{self, Request};

    let request = Request::post("https://api.example.com/todos")
        .header("Content-Type", "application/json")
        .body(serde_json::to_vec(&serde_json::json!({
            "title": "foo",
            "body": "bar",
            "userId": 1,
        })).expect("Failed to serialize request"))
        .expect("Failed to build request");

    let response = http::send(request).await.expect("Request failed");
    let status = response.status();
    assert!(status.is_success(), "API returned HTTP {status}");

    let data: serde_json::Value = http::response_json(response)
        .await
        .expect("Failed to parse response");
    println!("Body: {data}");
    ```

    Use `.body(Vec::new())` for an empty GET request. Set authentication with an ordinary `Authorization` header, for example `.header("Authorization", format!("Bearer {token}"))`; obtain the token from configuration and do not log it.

    `send` accepts `Request<Vec<u8>>` and returns `Result<Response, Error>`. It does not reject unsuccessful HTTP status codes, retry requests, or follow redirects automatically. Inspect `response.status()` and `response.headers()` before consuming the response. Handle request construction, transport, body reading, and decoding errors in your agent's error type rather than panicking in production code.

    Choose `http::response_bytes(response)` for `bytes::Bytes`, `http::response_text(response)` for `String`, or `http::response_json::<T>(response)` for a deserialized value. Each helper is async, returns a `Result`, and consumes the whole response. The JSON helper requires the SDK's `json` feature, enabled by default.

    For large responses, stream `response.into_body()` with `http_body_util::BodyExt` instead of collecting it. The default response body is `golem_rust::wasip3::http_compat::IncomingResponseBody`. For streaming uploads or low-level control, use `golem_rust::wasip3::http::client` and `golem_rust::wasip3::http::types`, or the reexported `golem_rust::wasip3::http_compat` adapters. Native sockets are not available.

    See [Making outgoing HTTP requests (Rust)](/next/how-to-guides/rust/golem-make-http-request-rust) for GET, JSON POST, authentication, and error-handling examples.
</Tabs.Tab>

<Tabs.Tab>
    HTTP requests can be made with the standard `fetch` function through Scala.js interop.

    For example:

    ```scala
    import scala.scalajs.concurrent.JSExecutionContext.Implicits.queue
    import scala.scalajs.js
    import scala.scalajs.js.Thenable.Implicits._

    for {
      response <- js.Dynamic.global
        .fetch(
          s"http://localhost:$port/todos",
          js.Dynamic.literal(
            method = "POST",
            headers = js.Dynamic.literal(
              "Content-Type" -> "application/json"
            ),
            body = js.JSON.stringify(
              js.Dynamic.literal(
                title = "foo",
                body = "bar",
                userId = 1
              )
            )
          )
        )
        .asInstanceOf[js.Promise[js.Dynamic]]
        .toFuture
      data <- response.json().asInstanceOf[js.Promise[js.Dynamic]].toFuture
    } yield println(s"Body: ${js.JSON.stringify(data)}")
    ```

</Tabs.Tab>

<Tabs.Tab>
    The current MoonBit SDK provides an async wrapper around Preview 3 `wasi:http`. Import `golemcloud/golem_sdk/http` as `@http`, construct an `@http.Request` with its generated accessors, and pass it to `@http.send`:

    ```moonbit
    async fn send(request : @http.Request) -> Result[@http.Response, @http.ErrorCode] {
      @http.send(request)
    }
    ```

    This is the exact SDK wrapper signature. Request bodies and response bodies are async byte streams; consume the full response stream before decoding JSON, and use `moonbitlang/core/encoding/utf8` rather than character-to-byte casts.

</Tabs.Tab>

<Tabs.Tab>
    HTTP requests can be made with the standard `net/http` package. The Go SDK installs its `wasi:http` transport as `http.DefaultTransport`, so `http.Get`, `http.DefaultClient`, and client libraries built on `net/http` work without extra setup.

    For example:

    ```go
    import (
        "bytes"
        "encoding/json"
        "fmt"
        "log/slog"
        "net/http"

        "github.com/golemcloud/golem/sdks/go/golem"
    )

    type ExampleRequest struct {
        Title  string `json:"title"`
        Body   string `json:"body"`
        UserID uint16 `json:"userId"`
    }

    payload := golem.Must(json.Marshal(ExampleRequest{Title: "foo", Body: "bar", UserID: 1}))

    response := golem.Must(http.Post(
        fmt.Sprintf("http://localhost:%d/todos", port),
        "application/json",
        bytes.NewReader(payload),
    ))
    defer response.Body.Close()

    var data map[string]any
    golem.Must0(json.NewDecoder(response.Body).Decode(&data))

    slog.Info("Body", "data", data)
    ```

    Raw sockets (`net.Dial`) are not available in Go agents; outgoing HTTP goes through `net/http`.
