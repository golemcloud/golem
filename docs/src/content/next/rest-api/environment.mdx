# Environment API

## Upload a content-addressed initial agent file for deployment in this environment
Path|Method|Protected
---|---|---
`/v1/envs/{environment_id}/initial-agent-files`|POST|Yes





**Request Form**: `multipart/form-data`

> Make sure to include `Content-Type: multipart/form-data` Header

**Field `file`**: string binary

**Example Response JSON**

```json copy
{
  "contentHash": "string",
  "size": 0
}
```
