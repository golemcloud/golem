# Golem documentation

Golem is an open-source durable runtime for agents, their tools, and their artifacts. Agents keep their memory, files, and in-progress work through crashes, restarts, and deployments. Tools run in isolated sandboxes that can work on an agent's durable filesystem. Artifacts, such as web pages, reports, and live streams, are served from the same deployment. Permission cards limit what each agent may do.

The **Golem runtime** runs on your machine or on your own servers. **Golem Cloud** is the hosted service that runs it for you; it is in Developer Preview, for building and trying things out. This documentation covers both and notes where they differ.
