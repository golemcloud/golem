# Resource metering

The worker executor can meter three resource usage dimensions independently:

- Wasmtime fuel for compute usage
- Allocated linear-memory byte-time
- Filesystem allocated-byte-time

All three dimensions are disabled by default. This is the expected configuration for Golem OSS and self-hosted enterprise deployments that run on customer hardware.

```toml
[resource_usage_metering]
compute = false
memory = false
filesystem = false
```

Set only the dimensions that the deployment exports for billing. For example, a deployment that meters compute and memory but not filesystem storage uses:

```toml
[resource_usage_metering]
compute = true
memory = true
filesystem = false
```

For the local single-binary server, the equivalent environment variables also require a monthly amount for each enabled dimension:

```shell
GOLEM__RESOURCE_USAGE_METERING__COMPUTE=true
GOLEM__RESOURCE_USAGE_METERING__MEMORY=true
GOLEM__RESOURCE_USAGE_METERING__FILESYSTEM=false
GOLEM__INITIAL_PLANS__DEFAULT__MONTHLY_COMPUTE_GCU=1000
GOLEM__INITIAL_PLANS__DEFAULT__MONTHLY_MEMORY_GB_SECONDS=100000
```

The local server preserves whether each amount was supplied. If an enabled dimension has no amount, startup fails instead of treating the omission as a zero hard cap. An explicit `0` is valid and creates an exhausted hard cap. Amounts supplied for disabled dimensions are preserved in the local Plan, and each dimension remains independent.

Filesystem metering requires a managed XFS root and separate durable and ephemeral amounts:

```shell
GOLEM__RESOURCE_USAGE_METERING__FILESYSTEM=true
GOLEM__INITIAL_PLANS__DEFAULT__MONTHLY_DURABLE_STORAGE_GB_MONTH=100
GOLEM__INITIAL_PLANS__DEFAULT__MONTHLY_EPHEMERAL_STORAGE_GB_MONTH=25
GOLEM__FILESYSTEM_STORAGE__MANAGED_XFS_ROOT_DIR=/var/lib/golem/managed-xfs
```

The managed XFS root cannot be combined with the deterministic agent filesystem root. Durable and ephemeral storage are separate limits; configuring one does not provide or change the other. When filesystem metering is disabled, managed XFS may still be configured for project quotas without enabling storage billing.

## Metering and enforcement

These switches control usage measurement and export. They do not control resource enforcement.

| Metering switch | Behavior when disabled | Controls that remain active |
| --- | --- | --- |
| `compute` | Fuel consumption is not accumulated or exported. Cumulative fuel is treated as unlimited. | Epoch-based interruption and executor scheduling |
| `memory` | Linear-memory byte-time is not accumulated or exported. | Per-agent memory limits, measured admission, and memory-pressure eviction |
| `filesystem` | Allocated filesystem byte-time is not accumulated or exported. | Managed XFS project quotas, filesystem-object limits, physical-pressure recovery, lifecycle, replay, and cleanup |

Managed XFS does not enable storage billing. A self-hosted deployment may use managed XFS and quotas while leaving `filesystem = false`.

### Current filesystem exceptions

Disabling filesystem metering stops byte-time accumulation and export, but two synchronous allocation observations remain in the current filesystem lifecycle:

- Filesystem operation completion may still read allocated usage.
- A failure while making that observation may fail the guest I/O operation.

These observations belong to the sealed GOL-416 filesystem protocol. Removing them requires an approved GOL-490 protocol amendment. The `filesystem` switch does not bypass them.

## Deployment modes

| Deployment | Compute | Memory | Filesystem |
| --- | --- | --- | --- |
| OSS or self-hosted default | Disabled | Disabled | Disabled |
| Enterprise or on-premises default | Disabled | Disabled | Disabled |
| Hosted | Explicit deployment choice | Explicit deployment choice | Explicit deployment choice |

Hosted manifests are maintained outside this repository. Their operators must explicitly enable each billed dimension during deployment. The worker executor does not infer metering from a registry connection, account, plan, quota, storage backend, or usage fields in registry messages.
