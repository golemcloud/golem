# Read-only Effect methods

Set `readOnly` on a `method`; handlers must remain ordinary Effects and must not mutate state or perform writes.

```ts
value: method({ input: {}, success: Schema.Number, readOnly: true })
cached: method({
  input: {},
  success: Schema.String,
  readOnly: { cache: { ttlNanos: 5_000_000_000n }, usesPrincipal: false },
})
```

Use `{ cache: "no-cache", usesPrincipal: true }` when the response depends on the caller. Do not mark a method read-only merely because its return type is immutable.
